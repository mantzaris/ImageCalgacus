\section{\uppercase{Introduction}}
\label{sec:introduction}
Autoregressive models make it possible to carry information through choices made during generation. A language model can select a token according to a hidden symbol, and a pixel model can do the same with a channel value. This creates a communication problem beyond producing a plausible sample. The receiver must recover the intended bytes from the object actually delivered, not from the sender's internal representation. A text file does not preserve token identifiers, and a PNG contains pixels rather than the latent state or probability trace used to generate them.\aifootnote

Calgacus transfers token ranks between contexts to conceal meaningful text in other text of the same token length \cite{calgacus}. Its generalization to other discrete autoregressive domains is explicit. RankCloak subsequently studies bounded byte-to-rank encodings, entropy gating and concealment of cryptographic artifacts \cite{rankcloak}. These ideas provide a useful starting point, but rank inversion with a preserved token sequence is a weaker endpoint than recovery from saved UTF-8. Independently, Pixel-Stega already combines PixelCNN++ with arithmetic coding to carry bits through generated images \cite{pixelstega}. Thus neither crossing modalities in principle nor applying arithmetic coding to pixels is the advance sought here.

We develop a common, authenticated transport contract and use it to expose the interaction between coding, modality and the delivered artifact. The hidden objects are small canonical images or literal messages. Every method transports the same fixed-size encrypted packet within each payload group. Text generation enforces complete-prefix tokenization consistency, and image generation works with the discrete probabilities of observable RGB channel values. Independent receivers reconstruct model states from saved files. A separate evaluator compares recovered source bytes, keeping authentication distinct from exact equality.

This design supports four connected contributions. First, we integrate bidirectional artifact transport under one explicit packet, serialization and recovery contract. Second, we demonstrate how fixed-rank, gated and finite-precision arithmetic coding trade capacity, distributional change and runtime under that contract. Third, we measure detection with a declared observer, including paired rescoring of the same PNGs under one alternate conditioning row. Fourth, we establish a behavior-preserving GPU execution improvement through exact probability-stream, carrier and recovery comparisons. These are contributions in evaluated protocol integration and empirical characterization, not new cryptographic primitives or new definitions of rank coding.

The prospective study contains 20 held-out payload groups in each direction and three methods, giving 120 transmissions. Fixed and gated coding recover all 20 payloads in each direction. Arithmetic A1 recovers all PNG payloads but no complete text payload under the frozen 2,048-token cap. This asymmetry is informative. Matching a model's distribution can limit the amount of recoverable information along a particular generated trajectory, whereas forcing four bits per eligible position imposes a different distribution. A later matched development benchmark reduces image encode-plus-decode latency from 177.82 to 34.64 seconds without changing the tested output. Together, these results make the practical costs and limitations of exact generative transport measurable rather than implicit.
